# Camada de Aplicação

## Conceito

A camada de Aplicação do Modelo TCP/IP abrange o funcionamento das camadas 5, 6 e 7 do Modelo OSI. Sendo a primeira das 4 (ou 5) camadas, fornecendo protocolos e serviços de rede utilizado pelas aplicações para se comunicarem.

A camada de Aplicação inclui protocolos e serviços de rede, como:

- DNS;
- DHCP;
- WWW;
- HTTP ou HTTPS;
- Entre outros.
