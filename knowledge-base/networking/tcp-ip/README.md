# Modelo TCP/IP

> "O TCP/IP possibilita a criação de um serviço universal e pode ser comparado ao sistema telefônico e à adoção da bitola padrão pelas ferrovias no Século XIX, ou com a adoção de protocolos comuns de sinalização por todas as companhia telefônicas."  
> — Tanenbaum (2003, p. 59)

O Modelo TCP/IP, assim como o Modelo OSI, possui uma organização em camadas. Porém, diferente do Modelo OSI, que possui 7 camadas, o TCP/IP geralmente é apresentado com 4 camadas, podendo apresentar 5, dependendo do material utilizado e os dois princiais protocolos: TCP e UDP.
