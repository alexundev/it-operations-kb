# Camada 7 — Aplicação

## Conceito

A Camada de Aplicação é a camada do Modelo OSI mais próxima do usuário, fornecendo serviços de rede utilizados pelas aplicações.

Ela permite a comunicação entre aplicações por meio de protocolos específicos, como HTTP e HTTPS, utilizados na comunicação entre clientes e servidores web.

## Visão de Troubleshooting

Investigar problemas relacionados aos serviços e protocolos utilizados pelas aplicações, como HTTP e DNS.
